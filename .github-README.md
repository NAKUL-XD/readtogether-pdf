# ReadTogether - Collaborative PDF Reading App

A real-time collaborative PDF reading platform where users can read together, chat, and annotate documents synchronously.

## 🚀 Deployed Application

- **Frontend**: Deployed on Vercel
- **Backend**: Deployed on Railway
- **Database**: MongoDB Atlas

## ✨ Features

- 📖 Real-time synchronized PDF reading
- 💬 Live chat while reading
- 🎨 Collaborative annotations (draw, highlight, erase)
- 🔖 Bookmarks
- 👥 Multi-user support
- 🌓 Multiple reading modes (light, dark, sepia)
- 📱 Responsive design (mobile, tablet, desktop)
- 🔗 Easy invite links with room codes

## 🛠️ Tech Stack

### Frontend
- React + TypeScript + Vite
- Tailwind CSS
- Framer Motion
- Zustand (state management)
- Socket.IO Client
- React-PDF

### Backend
- Express + TypeScript
- Socket.IO
- MongoDB + Mongoose
- JWT Authentication
- Multer (file uploads)

## 🚀 Local Development

### Prerequisites
- Node.js 18+
- MongoDB (local or Atlas)
- npm or yarn

### Setup

1. Clone the repository
```bash
git clone <your-repo-url>
cd pdf
```

2. Install dependencies
```bash
npm install
```

3. Setup environment variables
```bash
cp .env.example .env
# Edit .env with your configuration
```

4. Run the application
```bash
npm run dev
```

- Frontend: http://localhost:3000
- Backend: http://localhost:4000
